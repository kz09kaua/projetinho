# 🏥 Minha UBS

<p align="center">
Sistema web desenvolvido para modernizar e facilitar o gerenciamento de uma Unidade Básica de Saúde (UBS), oferecendo diferentes níveis de acesso para pacientes, atendentes e administradores.
</p>

---

# 📖 Sobre o Projeto

O **Minha UBS** é um sistema desenvolvido como **Projeto Integrador**, com o objetivo de informatizar processos de atendimento em uma Unidade Básica de Saúde, proporcionando maior organização, praticidade e eficiência no gerenciamento dos serviços.

A plataforma possui diferentes níveis de acesso, permitindo que cada usuário visualize apenas as funcionalidades relacionadas ao seu perfil.

O sistema foi desenvolvido utilizando tecnologias modernas de desenvolvimento web, priorizando desempenho, organização do código e uma interface intuitiva.

---

# 🎯 Objetivos

- Digitalizar processos internos da UBS.
- Facilitar o agendamento de consultas.
- Organizar filas de atendimento.
- Gerenciar histórico médico.
- Controlar vacinação.
- Auxiliar no gerenciamento de medicamentos.
- Melhorar a comunicação entre pacientes e profissionais da saúde.
- Centralizar informações em um único sistema.

# 💻 Instalação

Clone o projeto

```bash
git clone https://github.com/seuusuario/minha-ubs.git
```

Entre na pasta

```bash
cd minha-ubs
```

Instale as dependências

```bash
npm install
```

Execute o projeto

```bash
npm run dev
```
